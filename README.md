# PR 协作练习

我会创建一个 `test.txt`，初始内容：

```text
a

b

c

d

e

f

g
```

目标是最终变成：

```text
A

B

C

D

E

F

G
```

分工：

- 李星谕：A
- 李佳奇：B
- 刘俊辉：C
- 罗锐：D
- 黄鹏：E
- 肖俊：F
- 周佳睿：G

每个人只修改自己负责的一个字母，**不要删除中间的空白行**。

修改完成后：

1. Commit
2. Push 到自己的分支
3. 创建 PR：`自己的分支 → main`

每个人对应一个 PR。

**注意：只提交 PR，不要自己 Merge。PR 的方向只能是 `自己的分支 → main`，所有 PR 由李星谕检查并 Merge。**
